# 任务 Brief：JobHub 直招 · Web 端 UI 设计稿（pure-image）

## 任务与事实

- **主题与主体**：为「收集直招好工作的应用」设计 Web 端 UI 视觉稿。直招定义（用户原话要点）：公司官网《加入我们》超链接跳转提供的工作岗位。产品名采用设计稿内品牌名 JobHub 直招（此前 MasterGo 方案已定）。
- **目标与受众**：求职者（希望绕过中介、直达企业官网官方招聘入口）。阅读环境为桌面浏览器 Web 端。希望形成认知：这里的岗位 100% 来自企业官网《加入我们》，信息真实可溯源；行动：搜索、筛选、查看详情、收藏。
- **产物与路线**：Web 端高保真 UI 设计稿（图片），pure-image 路线，`image_gen` 从零生成。共 2 张：① 职位列表页（首页主界面）；② 职位详情页。均为 16:9 横版 Web 界面。用户已在交互确认中选择「改用创意设计出图」（MasterGo 连接失败后的替代交付通道）。
- **输入与来源**：无参考图、无品牌母版、无用户上传资产。设计来源此前已由用户确认为「自由绘制（free-draw）」。示例职位数据为演示数据（非用户提供、非真实招聘信息），仅用于展示 UI 布局。
- **事实边界**：页面内全部职位、公司、薪资、时间均为演示占位内容，不构成真实招聘信息；品牌名 JobHub 为设计用名。UI 应展示用户点名的关键信息维度：任职要求、岗位相关介绍、发布时间、联系方式、工作地址、最后更新时间。
- **保留与修改**：必须覆盖用户点名信息维度；必须体现「官网《加入我们》直招」的来源标签；整体美观排版。禁止伪造真实公司招聘事实（用演示数据标注）。
- **决策优先级**：用户锁定项＝直招来源定义＋6 类关键信息维度＋Web 端美观排版；品类规则＝pure-image 完整成品；Agent 可裁量＝配色、布局细节、演示数据。

## 整体方案与逐单元内容

- **总方案**：列表页建立「官网直招 = 真实可溯源」的第一印象（顶部导航 + 深蓝渐变 Hero 搜索区 + 左侧筛选栏 + 右侧职位卡片流 + 分页 + 页脚）；详情页承接列表页视觉，完整呈现岗位介绍、任职要求、发布时间、联系方式、工作地址、最后更新时间与官网《加入我们》直招入口。
- **视觉命题与注意力路径**：第一焦点＝Hero 搜索框与「官网直招」绿色标签；第二阅读层＝职位卡片（职位名、薪资、公司、地点）；收束点＝「查看详情」按钮与「来源：XX官网《加入我们》」溯源信息。
- **数量与顺序**：2 屏（列表 → 详情），同一视觉系统串联。
- **每屏设计单元**：
  1. 列表页：顶部导航（Logo＋菜单＋搜索＋登录）；Hero（信任徽章「100% 企业官网《加入我们》直招」＋大搜索框＋热门关键词）；左侧 260px 筛选栏（工作地点/职位类型/薪资范围/经验要求/直招来源）；右侧职位卡片（公司 Logo＋认证标、职位名、标签【官网直招/全职/经验】、薪资、发布时间、地点、来源《加入我们》、最后更新、收藏＋查看详情）；分页；页脚。
  2. 详情页：顶部导航（与列表页一致）；职位头部（公司 Logo、职位名、公司、标签、薪资、发布时间、地点）；主内容区（岗位介绍、任职要求清单）；侧栏信息卡（工作地址、联系方式、最后更新时间、官网《加入我们》直招入口按钮）；底部相关职位；页脚。
- **尺寸策略**：两张均 16:9 横版 Web 界面稿（对应 Web 桌面浏览器展示比例）；列表页为宽幅整页布局，详情页同宽幅。
- **文字承载**：纯生图路线，可见文字随图生成，Prompt 内用引号逐字给出关键文案；演示数据需保持克制（少量示例职位即可）。

## Visual 决策（追加）

- **风格与依据**：现代 SaaS 招聘平台的「可信、清爽、专业」视觉语言；扁平界面 + 细腻圆角卡片 + 柔和投影；主色深蓝系（#1E3A8A→#2563EB→#3B82F6 渐变），强调色绿色（#059669）专用于「官网直招」标签，中性灰底（#F5F7FA）承托内容。延续此前 MasterGo 列表页方案的主视觉决策。
- **决策边界**：锁定 16:9、深蓝渐变 Hero、绿色「官网直招」标签、左侧筛选栏布局；演示职位不超过 4 条（列表页）、详情页 1 条，避免文字密度过高导致 AI 渲染错乱。
- **配色与文字系统**：主色深蓝渐变（Hero 区）、主文字近黑 #111827、次要文字 #6B7280/#9CA3AF、绿色强调 #059669/#ECFDF5；文字角色：Hero 大标题（40px 级）> 职位名（18-20px 加粗）> 元信息（12-13px 次要色）。
- **图片系统**：公司 Logo 使用几何色块 + 首字母图形占位（圆角方形色块内放公司名首字），不绘制真实品牌 Logo。
- **背景系统**：整页浅灰底 #F5F7FA，白色卡片承载职位信息；Hero 深蓝渐变；页脚白色。
- **每屏相对构图**：列表页顶部导航 64px 高；Hero 占约 24% 高度居中；下方主体左右分栏（左筛选 260px、右内容区自适应，职位卡纵向排布 3-4 张）；详情页左侧主内容约 62%、右侧信息卡约 32%。
- **容器决策**：职位卡片用白色圆角 16px 卡片 + 1px 浅边 + 柔和投影，内部上下分区（上：公司/职位/标签/薪资；下：地点/来源/更新 + 操作按钮）；筛选栏为白色卡片；详情页信息卡同样式。
- **跨单元连续性**：两屏共享顶部导航、Logo、配色与「官网直招」绿色标签语言，保证同产品一致感。
- **视觉验收条件**：可一眼识别是求职应用；「官网直招」标签醒目且唯一使用绿色；6 类信息维度（任职要求/介绍/发布时间/联系方式/地址/最后更新）在两屏中均可见；无乱码、无真实品牌 Logo 侵权；界面无大面积留白空洞。
- **视觉效果生产规范**：按 pure-image 指令指南编译：总览句→分区扫描（上→下、左→右）→文字清单→画幅确认；逐字给出关键文案并用中文引号包裹；禁止额外文字、乱码、水印、伪 Logo。
- **视觉效果验收规范**：生成后核验比例 16:9、主体结构完整、文字可读、无侵权 Logo、信息维度覆盖、风格一致。
