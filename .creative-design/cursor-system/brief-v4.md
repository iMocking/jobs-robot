# JobHub 光标系统 v4（鸣潮式 · 细锐白科技）— 设计 Brief

## 背景与变更
- v3（画布 `0Mh8KgdO-4LQXlSvpSM-0201`）被用户判定需调整为"鸣潮那种鼠标光标"。
- 鸣潮（库洛）光标审美：**极细锐利的白色箭头 + 科技线条**，克制发光，简洁锋利（区别于 v3 的粗壮霓虹晕）。

## 设计语言（核心变化）
1. **细锐几何**：箭头收窄为细长射线（宽约 4–6px、长 20px+），尖端极锐、尾部斜切；端头以斜切/尖角为主（linejoin miter），去掉 v3 圆润感。
2. **白色主体 + 双细描边**：主体白色填充（#FFFFFF）+ 深蓝黑外轮廓（#0F1B3D，1.1–1.4px，保证浅背景可见）+ 浅蓝内亮线（#38BDF8，0.6–0.8px，科技感）。
3. **克制辉光**：细浅青外晕（1.6px @0.22）仅用于点缀，不再用 v3 的粗晕。
4. **细节**：text 两端蓝色刻度线；copy 白色圆角方 + 蓝加号；crosshair 细线十字 + 中心点；move 细四向箭头；禁用态克制的浅红。
5. viewBox 32，主体居中 24（偏移 +4），热点与 v3 相同（arrow 5,5 / pointer 18,7 / 中心 16,16 / zoom 15,15）——style.css 无需再改。

## 风格板（index.html）鸣潮 HUD
- 深蓝黑底 + 细网格 + 蓝白能量线条装饰；卡片细边框斜切角（更细更锐）、白字、浅蓝点缀；标题"细锐白 + 浅蓝"科技字。
